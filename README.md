## Висновки

> Коротко порівняйте швидкість збіжності методів за результатами обчислень.
Метод Сімпсона дає точніший результат за меншу кількість ітерацій ніж метод трапецій та прямокутників. Якщо порівнювати трапеції та прямокутники, то можна помітити невелику перевагу для прямокутників, але вона є менш суттєвою порівняно з методом Сімпсона.
